## 6. C++エンジンの進め方(開発者が書く)

Claude は方針・ヒント・レビューだけを出す(CLAUDE.md の役割分担)。

- **段階1:分割なし** — 株式分割・併合のない銘柄・期間で、シグナル・約定・成績指標がリファレンスと一致する
- **段階2:分割あり** — 分割・併合の日の持ち株数の変更(docs/mvp.md 2.8)まで含めて一致する

pybind11 で Python から呼び出せるようにし、API からリファレンス実装と切り替えられるようにする。
