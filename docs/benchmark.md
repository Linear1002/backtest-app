# 比較の基準:買い持ちの仕様

移動平均クロスの成績だけを見ても、**売買のタイミングに意味があったのか**は分からない。
株価が2倍になった期間なら、売買ルールが下手でも利益は出る。そこで、同じ銘柄を同じ期間、ただ持ち続けた場合(**買い持ち**)と並べる。

このドキュメントは買い持ちの計算の正とする。計算の部品(約定・株数・分割・評価・指標)は `docs/mvp.md` と同じものを使い、ここでは違うところだけを決める。

## 1. どこに出すか

| 画面 | 出すもの |
|---|---|
| 1組のバックテストの結果 | 計算書に買い持ちの最終資産、成績表に買い持ちの値、資産額のチャートに買い持ちの線、日々の数値の表に買い持ちの資産額 |
| 総当たりの結果 | 選ぶ期間・検証期間それぞれの買い持ちの成績と、検証期間で買い持ちを上回った組み合わせの数(`docs/sweep.md` 7章) |

## 2. 定義

1. **買うと決める日**:期間内の最初の有効日 `t0` の終値で、買いのシグナルが出たものとする(`docs/mvp.md` 2.1 の有効日)
2. **約定**:次の有効日の始値で約定する。約定価格・株数・手数料は `docs/mvp.md` 2.6・2.7 と同じ
   - 移動平均クロスも、最初に買えるのは期間の2日目以降の有効日になる(当日の終値で判定 → 次の有効日の始値で約定)。同じ条件で比べるため、買い持ちも同じ決まりにする
   - 期間内に `t0` より後の有効日がなければ、買わない
   - 資金不足(売買単位の株数を買えない)で約定しなかったら、そのあとは買い直さない
3. **持ち続ける**:売らない。分割・併合は `docs/mvp.md` 2.8 と同じ(端数は評価価格で現金に換える。併合で0株になったら、そのあとは現金のまま)
4. **1日の処理の順番**:`docs/mvp.md` 2.5 の手順1〜3(分割・併合 → 約定 → 評価)。手順4(シグナルの判定)はない
5. **評価と指標**:評価価格・資産額・日次リターンは `docs/mvp.md` 5章と同じ。期間の最後は評価するだけで売らない(清算コスト控除前。2.9)
   - 出す指標:総リターン・年率リターン・最大ドローダウン・シャープレシオ(定義・計算の順番は 5章・6章と同じ)
   - 出さない指標:勝率・取引回数(売らないので、決済した取引がない。併合で0株になったときだけ決済になるが、それも数えない)
6. **読み込む範囲**:移動平均を使わないので、ウォームアップはない。期間内の営業日のレコードだけを使い、`docs/mvp.md` 3.7 のデータのチェックもこの範囲で行う

パラメータは、移動平均クロスと同じ手数料率・スリッページ率・初期資金・売買単位・年間の営業日数を使う(日数は使わない)。

## 3. どこで計算するか

- **Python のリファレンス実装(`engine/reference/benchmark.py`)だけで計算する。** C++ 版・CUDA 版の約束(`docs/cpp/contract.md`)には入れない
  - 計算は1回だけで軽い。計算エンジンを C++ 版に切り替えても、買い持ちは同じ Python の関数で計算する
  - 買いの約定と株数(`fill_buy`)・分割・併合の処理(`apply_split_or_merger`)・評価価格・指標は、移動平均クロスと**同じ関数**を呼ぶ(買い持ちのために書き直さない)
- 1組のバックテストでは、移動平均クロスと同じ期間・同じパラメータで計算する
- 総当たりでは、選ぶ期間・検証期間のそれぞれで計算する(検証期間も持ち越しなしで、その期間の最初から)
- **買い持ちを買えなかったとき**(資金不足・買う日がない)は、**比べない**。値は初期資金のままで、比べると現金と比べることになるため。
  1組の結果では理由を書き、チャート・成績表・日々の表に買い持ちを出さない。総当たりでは期間ごとに理由を書き、「買い持ちより良かった数」を出さない
- **買い持ちの計算だけがエラーになったとき**(データの異常:株数の桁あふれ)は、結果全体をデータの異常として返す(1組は 422、総当たりも始める前の 422)。
  買い持ちが読む範囲(期間)は、移動平均クロスが確かめる範囲(ウォームアップ〜期間)に含まれるので、ほかのデータの異常は先に移動平均クロスで見つかる

## 4. 正しさの確かめ方

- 手で計算したケース:分割、端数の出る併合、併合で0株、期間の最初が売買不成立の日、資金不足、`t0` のあとに有効日がない期間
- **移動平均クロスとの一致**:移動平均クロスが「1回だけ買って、期間の最後まで持った」とき、その買いのシグナルの日を開始日にした買い持ちは、その日から最後の日まで、資産額が移動平均クロスと**完全に同じ**になる。
  同じ日に、同じ現金で、同じ始値で買い、同じ分割の処理を通るため。テストでは架空データの全銘柄と、いくつかの日数の組で、この性質を確かめる

## 5. 読み方の注意(画面に出す)

- **配当を含めない。** 買い持ちは期間中ずっと株を持つので、配当を含めないことで不利になる分は、移動平均クロスより買い持ちのほうが大きい(実際に持ち続けた場合は、ここに出る値より良いことが多い)
- 期間の最後は清算コスト控除前(移動平均クロスと同じ)。買い持ちは最後まで必ず株を持つので、売買ルールが最後に売り切っているときは、
  その売りの費用の分だけ買い持ちが有利になる(画面の注記に書く)
- 「良い・悪い」は、画面に出す桁(シャープレシオは小数2桁、% は小数2桁)で同じなら「同じ」と書く。
  総当たりの「買い持ちより良かった数」は、丸める前の値で数える(同じ値は数えない)
- 「買い持ちより良かった・悪かった」は、この銘柄・この期間での比較でしかない。総当たりで「検証期間で買い持ちを上回った組み合わせ」を数えるのは、選ぶ期間の1位がたまたまかどうかを見るためで、上回った組み合わせを選び直すためではない(`docs/sweep.md` 7章)
